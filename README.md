## 🌟 Introduction

**Back to School — Vanilla Magic Page** is a specialized showcase for the back-to-school season, extracted from a versatile digital greeting card architecture system. The project demonstrates the power of **Web Standards** in creating smooth visual, audio, and interactive effects while maintaining a super lightweight file size.

| ⚡ Criteria | 🎯 Technical Solution |
| --- | --- |
| **Extremely Fast Speed** | Independent of React/Vue/Tailwind — Pure HTML & CSS |
| **Canvas Effects** | Handwritten confetti algorithm for optimized FPS |
| **Easy to Edit** | Configure all text and effects via JSON file |
| **Ready to Deploy** | Completely free hosting on GitHub Pages |

---

## 🛠️ Technical Architecture

- **Rendering Engine:** Utilizes HTML `<template>` to render flexible page structures.
- **Canvas FX:** High-performance rendering engine that automatically adjusts to screen size (Responsive).
- **JSON Driven:** Change content, theme colors, and effects simply by updating JSON configuration without interfering with JS logic.

## 🚀 Local Run Guide

1. Fork or clone this repository:

```bash

git clone https://github.com/goldhoang/vanilla-magic-back-to-school.git

```

2. Open with a local server (e.g., Live Server in VS Code or the `npx serve` command).

> **Note:** Do not open the `index.html` file directly in `file://` format to avoid CORS errors when reading JSON files.
